# Simulación sensor

Para hacer la simulación del sensor es necesario seguir los siguientes pasos:

* 1- Abrir la terminal den la carpeta que contenga todos los archivos del sensor
* 2- Correr el comando make sim
* 3- Si se quiere hacer una visualización de las señales más importantes, en GTKwave deberia ser posible ir a "File", "Read save file" y abrir el archivo llamado "SENSOR.gtkw"
